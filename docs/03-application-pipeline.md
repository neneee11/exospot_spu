# 03 · Application Pipeline
**ExoSpot – แอปทำกายภาพเข่าที่บ้าน สำหรับผู้สูงอายุ ลูกหลาน และนักกายภาพ**

> หน้าที่: รับข้อมูลผู้ใช้ → เปิด session ฝึกที่ใช้ AI ตรวจท่า → แสดงผล real-time → บันทึกผล → แสดงสถิติ → ส่งสรุปให้ลูกหลานทาง LINE
> UI อ้างอิงสไตล์ health app แบบ glassmorphism โทนเขียวเทา (ตาม reference) ปรับให้ผู้สูงอายุใช้ง่าย

---

## 1. ผู้ใช้ 3 กลุ่ม
- **ผู้สูงอายุ (ผู้ฝึก):** ใช้หน้าหลัก หน้าฝึก และหน้าสรุปผล
- **ลูกหลาน / ผู้ดูแล (ผู้ซื้อ):** ตั้งค่าบัญชีให้ผู้สูงอายุ ดูสถิติ และรับแจ้งเตือนทาง LINE
- **นักกายภาพ:** ตั้งเกณฑ์ความปลอดภัยและโปรแกรมฝึกรายบุคคล

---

## 2. ภาพรวม Pipeline

```
[Onboarding / Profile]  ขอข้อมูลผู้ป่วย + ความยินยอม PDPA
   ▼
[Exercise Plan]  นักกายภาพหรือค่าเริ่มต้น กำหนดท่า จำนวนครั้ง และเกณฑ์
   ▼
[Pre-session]  เช็กกล้อง + เชื่อม ESP32 + ถามคะแนนปวดก่อนฝึก
   ▼
[Live Session]  AI Pipeline → แสดงโครงกระดูก + นับครั้ง + โค้ชเสียง (NLP) + ส่งสถานะไปกล่องไฟ ESP32 ↔ รับสถานะไฟกลับ
   ▼
[Session Summary]  แสดงผล + ถามคะแนนปวดหลังฝึก
   ▼
[Save]  บันทึก Supabase (เฉพาะตัวเลข ไม่มีวิดีโอ)
   ▼
[Notify]  Edge Function → LINE Messaging API → ลูกหลาน
   ▼
[Statistic / Dashboard]  กราฟรายสัปดาห์ สำหรับผู้สูงอายุ ลูกหลาน และนักกายภาพ
```

## 3. Design System (อ้างอิงจาก reference)

**สไตล์**
- Glassmorphism: การ์ดโปร่งแสง เบลอพื้นหลัง (`backdrop-filter: blur`)
- พื้นหลังไล่สีเขียวเทา (sage / teal) เช่น `#9fb5b2 → #5e7d79`
- สีหลัก (accent): เขียวเข้ม `#0f3b3a` ใช้กับแถบที่เลือกและกราฟแท่งวันปัจจุบัน
- สีเน้นความคืบหน้า: ส้ม `#f08a3c` ใช้กับวงแหวน progress
- สีสถานะ: เขียว `#22c55e` / เหลือง `#facc15` / แดง `#ef4444`
- การ์ดมุมโค้ง 24–28 px, ปุ่มเป็นทรงแคปซูล (pill)

**Navigation**
- แถบเมนูล่างทรงแคปซูล 4 แท็บ เหมือน reference: **หน้าหลัก · โปรแกรม · สถิติ · โปรไฟล์**
- แท็บที่เลือกขยายเป็นปุ่มสีขาวพร้อมชื่อ แท็บอื่นเป็นวงกลมไอคอน

**ปรับให้เหมาะกับผู้สูงอายุ**
- ตัวหนังสือเนื้อหาอย่างน้อย 18–20 px, ตัวเลขสำคัญ 32 px ขึ้นไป
- ปุ่มกดขนาดอย่างน้อย 56 px
- ใช้ภาษาไทยเป็นหลัก คำสั้น ไม่ใช้ศัพท์เทคนิค
- มีเสียงพูดนำในหน้าฝึก ไม่ต้องอ่านจอระหว่างทำท่า
- Font: IBM Plex Sans Thai หรือ Noto Sans Thai

## 4. หน้าจอและข้อมูล (ขออะไร / แสดงอะไร)

### 4.1 Onboarding & ตั้งค่าผู้ป่วย
ลูกหลานหรือนักกายภาพเป็นคนกรอกให้

**ขอข้อมูล**
- ชื่อ-นามสกุล, ชื่อเล่นที่ให้แอปเรียก (เช่น "คุณยายสมศรี")
- อายุ, เพศ, ส่วนสูง, น้ำหนัก (ใช้คำนวณ BMI เพราะน้ำหนักมีผลต่อข้อเข่า)
- ข้างที่เป็น: เข่าซ้าย / ขวา / ทั้งสองข้าง
- กลุ่ม: ยังไม่ผ่าตัด (อยู่ระหว่างรักษาตัว) / ผ่าตัดแล้ว (ระยะฟื้นตัว)
- ถ้าผ่าตัดแล้ว: วันที่ผ่าตัด และองศางอเข่าที่แพทย์อนุญาต
- โรคประจำตัว (เลือกได้หลายข้อ): เบาหวาน, ความดันโลหิตสูง, น้ำหนักเกิน, อื่นๆ
- อุปกรณ์ช่วยเดินที่ใช้: ไม่ใช้ / ไม้เท้า / walker
- คะแนนปวดเริ่มต้น 0–10
- เชื่อม LINE ของลูกหลาน (สแกน QR เพิ่มเพื่อน LINE OA)
- รหัสนักกายภาพ (ถ้ามี) เพื่อให้นักกายภาพเข้ามาดูข้อมูลได้
- ความยินยอม PDPA: ยินยอมเก็บข้อมูลสุขภาพ และรับรู้ว่าระบบไม่บันทึกวิดีโอ

**แสดงผล**
- สรุปข้อมูลก่อนบันทึก และ BMI ที่คำนวณให้

---

### 4.2 หน้าหลัก (Home) – อ้างอิงหน้าซ้ายของ reference

**ขอข้อมูล**
- ไม่มี (อ่านจากฐานข้อมูล)

**แสดงผล**
- ทักทาย: "สวัสดีค่ะ คุณยายสมศรี วันนี้พร้อมฝึกไหมคะ" + วันที่ภาษาไทย
- การ์ดสถิติวันนี้ (เลื่อนแนวนอน มีวงแหวน progress สีส้ม):
  - ทำวันนี้ 6/10 ครั้ง (ป้าย "ดี")
  - ท่าถูก 80% (ป้าย "ปานกลาง")
  - คะแนนปวดล่าสุด 3/10
- การ์ดโปรแกรมวันนี้ (แทน "Upper body strength"):
  - "ลุกจากเก้าอี้ 10 ครั้ง" · 2 เซต · ประมาณ 5 นาที
  - ปุ่มวงกลม ▶ เริ่มฝึก
- แจ้งเตือน: "ยังไม่ได้ฝึกรอบเย็นนะคะ"
- ไอคอนสถานะกล่องแจ้งเตือน (เชื่อมต่อแล้ว / ยังไม่เชื่อมต่อ) ที่มุมบน

---

### 4.3 โปรแกรม (Program)

**ขอข้อมูล**
- เลือกท่าที่จะฝึก (demo มีท่าเดียว: ลุกจากเก้าอี้)

**แสดงผล**
- รายการท่าที่นักกายภาพกำหนด พร้อมจำนวนครั้ง จำนวนเซต และเวลาโดยประมาณ
- ภาพหรือแอนิเมชันสาธิตท่า และคำแนะนำสั้นๆ
- ท่าที่ฝึกครบแล้ววันนี้มีเครื่องหมายถูก

---

### 4.4 ก่อนเริ่มฝึก (Pre-session)

**ขอข้อมูล**
- อนุญาตใช้กล้อง
- กด "เชื่อมต่อกล่องแจ้งเตือน" (Web Serial เลือกพอร์ต ESP32)
- คะแนนปวดก่อนฝึก 0–10 (ปุ่มหน้ายิ้มใหญ่ๆ 0 / 2 / 4 / 6 / 8 / 10)

**แสดงผล**
- ภาพกล้องพร้อมกรอบไกด์ "ให้เห็นตั้งแต่สะโพกถึงเท้า และเห็นเก้าอี้"
- เช็กลิสต์อัตโนมัติ: ✔ เห็นทั้งตัว ✔ แสงพอ ✔ กล่องแจ้งเตือนพร้อม
- ปุ่ม "เริ่มฝึก" กดได้เมื่อผ่านเช็กลิสต์
- ถ้าคะแนนปวด ≥ 7: แสดงคำเตือน "วันนี้ปวดมาก ควรพักหรือปรึกษานักกายภาพก่อนค่ะ"

---

### 4.5 ระหว่างฝึก (Live Session) – หน้าสำคัญที่สุดของ Demo

**รับข้อมูล (จาก AI Pipeline ทุกเฟรม)**
- `state` G/Y/R/O, `kneeAngle` ซ้าย-ขวา, `repCount`, `phase`, issue ที่ตรวจเจอ

**แสดงผล**
- ภาพกล้องเต็มจอ + โครงกระดูก ขาเปลี่ยนสีตามสถานะ (เขียว / เหลือง / แดง)
- ตัวเลขมุมเข่าข้างจุดเข่า
- ตัวนับครั้งใหญ่ "4 / 10" มุมขวาบน
- แถบสถานะด้านบน:
  - 🟢 "ดีมากค่ะ"
  - 🟡 "ระวังเข่าบิดเข้าในค่ะ"
  - 🔴 "หยุดก่อน ปรับท่าค่ะ"
  - ⚪ "กรุณาถอยให้กล้องเห็นทั้งตัวค่ะ"
- โค้ชเสียงพูดตามบุคลิกที่เลือก: นับครั้ง บอกครึ่งทาง/ครั้งสุดท้าย เตือนท่าผิด (ผิดซ้ำบอกวิธีแก้) ชมเมื่อแก้ท่าได้ (ดู `05-voice-coach.md`)
- กล่องข้อความแสดงสิ่งที่โค้ชพูดล่าสุด
- ส่งสถานะไปกล่องไฟ ESP32 ทันที และแสดง "ไฟบนกล่อง" ตามที่ ESP32 รายงานกลับ
- สั่งงานด้วยเสียงได้ (ถ้าเปิดไว้): เริ่ม / พัก / ต่อ / จบ / ได้กี่ครั้งแล้ว + แสดง "ได้ยินว่า…"
- ปุ่มใหญ่: ⏸ พัก · ⏹ จบ

---

### 4.6 สรุปผลหลังฝึก (Session Summary)

**ขอข้อมูล**
- คะแนนปวดหลังฝึก 0–10
- ความรู้สึก (ไม่บังคับ): ง่าย / พอดี / เหนื่อย

**แสดงผล**
- "เก่งมากค่ะ วันนี้ทำครบ 10 ครั้ง"
- ท่าถูก 8/10 ครั้ง (80%) แสดงเป็นวงแหวน
- จุดที่ต้องระวัง: เข่าบิดเข้าใน 2 ครั้ง, นั่งลงเร็ว 1 ครั้ง
- เวลาเฉลี่ยต่อครั้ง 3.4 วินาที
- มุมงอเข่า 90°–172°
- ปวดก่อนฝึก 4 → หลังฝึก 3
- ปุ่ม "ส่งผลให้ลูกหลาน" (ส่งอัตโนมัติได้ถ้าเปิดไว้ในตั้งค่า)

---

### 4.7 สถิติ (Statistic) – อ้างอิงหน้ากลางของ reference

**ขอข้อมูล**
- เลือกช่วงเวลา: สัปดาห์นี้ / เดือนนี้
- เลือกแท็บ: จำนวนครั้ง · ท่าถูก % · ความปวด

**แสดงผล**
- ตัวเลขหลักด้านบน เช่น "เฉลี่ย 9 ครั้ง/วัน"
- กราฟแท่ง ส.–ศ. (แท่งวันนี้สีเขียวเข้ม แท่งอื่นโปร่งแสง)
- การ์ดฝึกล่าสุด:
  - กราฟเส้นมุมเข่าระหว่างฝึก (แทน Heart rate)
  - ท่าถูก % (แทน Calories)
  - เวลาที่ฝึก (Durations)
- ข้อความสรุปอัตโนมัติ เช่น "สัปดาห์นี้เข่าบิดลดลง 40% เทียบกับสัปดาห์ก่อน"

---

### 4.8 โปรไฟล์ (Profile) – อ้างอิงหน้าขวาของ reference

**ขอข้อมูล**
- แก้ไขข้อมูลส่วนตัว น้ำหนัก และโรคประจำตัว
- ตั้งเวลาเตือนฝึก (เช้า / เย็น)
- เปิด-ปิดโค้ชเสียง, เลือกบุคลิกโค้ช (หลานสาวใจดี / โค้ชสายเชียร์ / เพื่อนขี้เล่น) พร้อมปุ่มลองฟัง
- เปิด-ปิดสั่งงานด้วยเสียง
- เปิด-ปิดการส่งผลให้ลูกหลานอัตโนมัติ

**แสดงผล**
- การ์ดผู้ใช้: รูป ชื่อ กลุ่มผู้ป่วย (ยังไม่ผ่าตัด / ผ่าตัดแล้ว)
- 3 ช่องข้อมูล: อายุ · ส่วนสูง · น้ำหนัก
- เมนูตั้งค่า: ข้อมูลส่วนตัว › · การแจ้งเตือน › · เสียง (toggle)
- เมนูการฝึก: ระดับโปรแกรม › · **จุดที่ต้องระวัง (Caution areas)** › แสดงเข่าข้างที่เป็นและข้อจำกัดจากแพทย์
- ผู้ดูแลที่เชื่อมไว้ (ลูกหลาน / นักกายภาพ)

---

### 4.9 หน้าลูกหลาน / ผู้ดูแล (Caregiver Dashboard)

**ขอข้อมูล**
- เข้าสู่ระบบด้วยบัญชีลูกหลาน (หรือเปิดจากลิงก์ใน LINE)

**แสดงผล**
- สถานะวันนี้: "คุณแม่ฝึกแล้ว 1 รอบ" หรือ "ยังไม่ได้ฝึก"
- กราฟสัปดาห์เหมือนหน้าสถิติ
- รายการเหตุการณ์ที่ต้องดู: ท่าผิดบ่อย, คะแนนปวดสูงขึ้น, ไม่ได้ฝึกติดกัน 2 วัน
- ปุ่ม "โทรหาคุณแม่" และ "ส่งข้อความให้กำลังใจ"

---

### 4.10 หน้านักกายภาพ (Physio Settings)

**ขอข้อมูล**
- ท่าที่ให้ฝึก จำนวนครั้ง จำนวนเซต และความถี่ต่อวัน
- เกณฑ์ความปลอดภัยรายบุคคล: valgus ratio, ความเร็วนั่งลง, asymmetry, องศางอเข่าสูงสุด (สำหรับผู้ผ่าตัด)

**แสดงผล**
- รายชื่อผู้ป่วยที่ดูแล และสถานะการฝึกล่าสุด
- ประวัติ session ละเอียดรายครั้ง (rep events)
- นักกายภาพเป็นคนอนุมัติเกณฑ์ AI ทำหน้าที่ตรวจตามเกณฑ์เท่านั้น (Human-in-the-loop)

## 5. ข้อความแจ้งเตือน LINE (ตัวอย่าง)

**หลังฝึกเสร็จ**
> 🦵 ExoSpot: คุณยายสมศรีฝึก "ลุกจากเก้าอี้" ครบ 10 ครั้งแล้ว
> ท่าถูก 80% · ระวังเข่าบิด 2 ครั้ง
> ปวดก่อน 4 → หลัง 3
> ดูรายละเอียด: [ลิงก์]

**ไม่ได้ฝึก**
> คุณยายสมศรียังไม่ได้ฝึกมา 2 วันแล้ว ลองโทรชวนคุยดูนะคะ

**ปวดมาก**
> คุณยายสมศรีให้คะแนนปวด 8/10 หลังฝึก แนะนำให้ปรึกษานักกายภาพค่ะ

## 6. Data Model (Supabase / Postgres)

**users** – บัญชีผู้ใช้
- `id`, `role` (patient / caregiver / physio), `name`, `line_user_id`

**patient_profiles** – ข้อมูลผู้ป่วย
- `user_id`, `nickname`, `age`, `sex`, `height_cm`, `weight_kg`
- `affected_side` (left / right / both), `group` (pre_op / post_op), `surgery_date`
- `comorbidities[]`, `walking_aid`, `baseline_pain`, `consent_at`

**care_links** – ความสัมพันธ์ผู้ป่วยกับผู้ดูแล
- `patient_id`, `caregiver_id`, `relation` (ลูก / หลาน / นักกายภาพ)

**exercise_plans** – โปรแกรมและเกณฑ์จากนักกายภาพ
- `patient_id`, `exercise`, `target_reps`, `sets`, `per_day`
- `thresholds` (JSON: valgus, velocity, asymmetry, maxFlex), `approved_by`

**sessions** – ผลการฝึกแต่ละรอบ (มาจาก AI session summary)
- `id`, `patient_id`, `exercise`, `started_at`, `duration_sec`
- `completed_reps`, `correct_reps`, `correct_percent`
- `alerts` (JSON), `avg_rep_sec`, `rom_min`, `rom_max`
- `pain_before`, `pain_after`, `feeling`

**rep_events** – รายละเอียดรายครั้ง (สำหรับนักกายภาพ)
- `session_id`, `rep`, `duration_sec`, `min_angle`, `max_angle`, `worst_state`, `issues[]`

ไม่มีตารางเก็บวิดีโอหรือภาพ

## 7. Data Flow ระหว่างระบบ

```
AI Pipeline ──(state ทุกเฟรม)──▶ Live Session UI ──▶ ESP32 (Web Serial)
     │
```

## 10. Flow Demo (ประมาณ 2 นาที)
1. เปิดหน้าหลัก เห็นสถิติวันนี้และโปรแกรม "ลุกจากเก้าอี้ 10 ครั้ง"
2. กดเริ่ม → เช็กกล้อง → เชื่อมกล่องแจ้งเตือน → ให้คะแนนปวดก่อนฝึก
3. ทำท่าถูก 3 ครั้ง: ไฟเขียว เสียงนับครั้ง
4. แกล้งหุบเข่า: ไฟแดงกะพริบ โค้ชพูด "หยุดก่อนค่ะ ระวังเข่าบิดเข้าใน" ทำผิดซ้ำโค้ชบอกวิธีแก้
5. พูดว่า "ได้กี่ครั้งแล้ว" โค้ชตอบจำนวนที่เหลือ
6. จบ session → โค้ชพูดสรุปผลที่ LLM แต่ง → ให้คะแนนปวดหลังฝึก
7. หยิบมือถือให้กรรมการดู ข้อความสรุปเด้งเข้า LINE และกราฟในหน้าสถิติอัปเดต

**ตัวสำรอง:** อัดวิดีโอ flow นี้เก็บไว้ และเตรียมฮอตสปอตมือถือ
