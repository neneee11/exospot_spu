# 02 · Hardware Pipeline
**ExoSpot – กล่องไฟ LED แจ้งเตือน (ESP32) · v0.3 ไม่มี buzzer**

> หน้าที่: รับสถานะจาก AI ผ่านสาย USB แล้วแสดงผลด้วยไฟ 3 สี และ **รายงานสถานะไฟจริงกลับไปที่แอป**
> เสียงแจ้งเตือนทั้งหมดย้ายไปอยู่ในแอป (โค้ชเสียงพูด ดู `05-voice-coach.md`)
> ไม่มี sensor สวมใส่ ตัวกล่องวางข้างเก้าอี้ที่ผู้สูงอายุนั่งฝึก

---

## 1. ภาพรวม Pipeline (สื่อสาร 2 ทาง)

```
[แอป: AI Pipeline]
   │  G / Y / R / O / C / P   (1 ตัวอักษร)
   ▼
[Web Serial · USB · 115200 baud]
   ▼
[ESP32]
   ├─ 1. อ่านคำสั่ง
   ├─ 2. เปลี่ยนไฟ (แดง = กะพริบเร็ว)
   ├─ 3. C = ไฟ 3 ดวงกะพริบฉลองเมื่อนับครั้งได้
   ├─ 4. Failsafe: ไม่ได้รับคำสั่งเกิน 3 วินาที → ดับ
   └─ 5. ตอบกลับ LED:x ทุกคำสั่ง
   │
   ▼  READY / LED:G|Y|R|O / TIMEOUT
[แอป]
   ├─ แสดง "ไฟบนกล่อง" เป็นไฟจำลองบนจอ (ตรงกับไฟจริง)
   └─ ไม่ได้รับ LED:x เกิน 2.5 วินาที → แสดง "กล่องไฟไม่ตอบสนอง"
```

---

## 2. แอป → ESP32 (Input ของกล่อง)

- `G` = ท่าถูกต้อง → LED เขียวติดค้าง
- `Y` = เริ่มเสี่ยง → LED เหลืองติดค้าง
- `R` = อันตราย → LED แดง **กะพริบเร็ว** (ทุก 200 ms) ดึงความสนใจแทนเสียง
- `O` = หยุด / ไม่พบคน → ดับทั้งหมด
- `C` = นับครั้งได้ → ไฟ 3 ดวงกะพริบพร้อมกัน 150 ms แล้วกลับสถานะเดิม
- `P` = ping → ขอสถานะปัจจุบัน (แอปส่งตอนเพิ่งเชื่อมต่อ)

กติกาการส่ง: ส่งทันทีเมื่อสถานะเปลี่ยน + ส่งซ้ำทุก 1 วินาทีเป็น heartbeat

---

## 3. ESP32 → แอป (Output ส่งข้อมูลกลับ)

- `READY` = บอร์ดเพิ่งเปิด/รีเซ็ต (แอปจะส่งสถานะปัจจุบันให้ใหม่ทันที)
- `LED:G` / `LED:Y` / `LED:R` / `LED:O` = สถานะไฟจริงบนกล่อง ส่งทุกครั้งที่ได้รับคำสั่ง (ทำหน้าที่เป็น ACK)
- `TIMEOUT` = ไม่ได้รับคำสั่งเกิน 3 วินาที ดับไฟแล้ว

**แอปใช้ข้อมูลนี้ทำอะไร**
- แสดงไฟจำลอง 3 ดวงในหน้าฝึก ("ไฟบนกล่อง: เขียว") ให้รู้ว่าไฟจริงตรงกับที่ AI สั่ง
- ตรวจสุขภาพกล่อง: ถ้าไม่ได้รับ `LED:x` เกิน 2.5 วินาที สถานะเปลี่ยนเป็น "ไม่ตอบสนอง" (จุดแดง)
- กล่องรีเซ็ตกลางทาง (ส่ง `READY`) แอปส่งสถานะปัจจุบันซ้ำให้อัตโนมัติ

---

## 4. ความหมายของไฟ (สำหรับผู้สูงอายุ)

- 🟢 เขียวติดค้าง = ทำท่าถูกต้อง
- 🟡 เหลืองติดค้าง = เริ่มเสี่ยง ควรปรับท่า
- 🔴 แดงกะพริบเร็ว = อันตราย หยุดหรือปรับท่าทันที
- ✨ กะพริบพร้อมกัน 3 ดวง = นับได้อีก 1 ครั้ง
- ดับทั้งหมด = ไม่ได้ฝึก / กล้องมองไม่เห็น / พัก

---

## 5. รายการอุปกรณ์ (BOM)

- ESP32 DevKit V1 × 1
- LED สีเขียว เหลือง แดง × อย่างละ 1 (แนะนำ 10 mm หรือ LED ความสว่างสูง ให้ผู้สูงอายุเห็นชัด)
- ตัวต้านทาน 220 Ω × 3
- Breadboard × 1 (หรือ PCB อเนกประสงค์ถ้าจะบัดกรีลงกล่อง)
- สาย jumper ผู้-ผู้ ประมาณ 6 เส้น
- สาย USB ที่ส่งข้อมูลได้ × 1
- กล่องพลาสติกหรือกล่องพิมพ์ 3D เจาะรูให้ไฟโผล่ (ใส่ฝาครอบขุ่นช่วยให้ไฟกระจายเห็นง่ายขึ้น)

**ตัดออกจากเวอร์ชันก่อน:** buzzer, ทรานซิสเตอร์ NPN, ตัวต้านทาน 1 kΩ, ไดโอด

---

## 6. การต่อวงจร

- ESP32 `GND` → ราง − ของ breadboard
- `GPIO25` → 220 Ω → LED เขียว ขายาว (Anode) / ขาสั้น (Cathode) → GND
- `GPIO26` → 220 Ω → LED เหลือง → GND
- `GPIO27` → 220 Ω → LED แดง → GND

```
GPIO25 ──[220Ω]──▶|── LED เขียว ── GND
GPIO26 ──[220Ω]──▶|── LED เหลือง ── GND
GPIO27 ──[220Ω]──▶|── LED แดง  ── GND
```

ถ้าต่อตามแบบเดิมไว้แล้ว **แค่ถอด buzzer, ทรานซิสเตอร์, 1 kΩ และสาย GPIO14 / 5V ออก** ส่วน LED ไม่ต้องแก้

**ข้อควรระวัง**
- ESP32 ใช้ logic 3.3V ห้ามป้อน 5V เข้าขา GPIO
- ห้ามใช้ GPIO 6–11 (ต่อกับ flash) และ GPIO 34–39 (input อย่างเดียว)
- ถอดสาย USB ทุกครั้งก่อนแก้วงจร

## 7. Firmware (`firmware/exo_alert_box/exo_alert_box.ino` v0.3)

ลำดับใน `loop()`:
1. อ่านคำสั่ง → G/Y/R/O เปลี่ยนไฟและตอบ `LED:x` · C กะพริบฉลอง · P ตอบสถานะ
2. ครบเวลากะพริบฉลอง → กลับไปแสดงสถานะเดิม
3. Failsafe: ไม่ได้รับคำสั่งเกิน 3,000 ms → ดับ ตอบ `TIMEOUT` และ `LED:O`
4. สถานะแดง → สลับเปิด/ปิดไฟแดงทุก 200 ms ด้วย `millis()` (ไม่ใช้ `delay()`)

**เปลี่ยนจาก v0.2**
- ลบโค้ด buzzer ทั้งหมด
- ไฟแดงกะพริบแทนเสียง
- `C` เปลี่ยนจากเสียงติ๊ดเป็นไฟกะพริบฉลอง
- เพิ่มการรายงานกลับ `LED:x` และคำสั่ง `P`
- ข้อความเปิดเครื่องเปลี่ยนจาก `EXO_READY` เป็น `READY`

## 8. แผนทดสอบ (Checklist)

- [ ] เสียบ USB แล้วไฟวิ่ง เขียว → เหลือง → แดง (self-test)
- [ ] Serial Monitor (115200) เห็น `READY`
- [ ] พิมพ์ `G` แล้วไฟเขียวติด และ Serial Monitor ตอบ `LED:G`
- [ ] พิมพ์ `R` ไฟแดงกะพริบ / พิมพ์ `C` ไฟ 3 ดวงกะพริบแล้วกลับสถานะเดิม
- [ ] หยุดส่งคำสั่ง ภายใน 3 วินาทีไฟดับเอง และเห็น `TIMEOUT`
- [ ] เชื่อมกับแอป: ไฟจำลองบนจอตรงกับไฟจริงทุกสถานะ
- [ ] ถอดสายระหว่างใช้งาน แอปขึ้น "สายหลุด" / กดรีเซ็ตบอร์ด แอปส่งสถานะคืนให้เอง

---

## 9. แผนต่อยอด
- เปลี่ยนจาก USB เป็น BLE ให้ใช้กับมือถือได้
- เปลี่ยนเป็น LED strip (WS2812) ทำแถบไฟแสดงความคืบหน้า เช่น ติดทีละดวงตามจำนวนครั้ง
- เพิ่มปุ่มกดใหญ่บนกล่องสำหรับ เริ่ม / พัก แล้วส่งกลับไปที่แอป (เช่น `BTN:START`)
