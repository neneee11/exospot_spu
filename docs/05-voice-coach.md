# 05 · Voice Coach (NLP)
**ExoSpot – โค้ชเสียงพูดภาษาไทยที่มีลูกเล่น**

> หน้าที่: แทน buzzer ด้วยเสียงพูดที่เป็นธรรมชาติ ไม่ท่องประโยคเดิมซ้ำ มีบุคลิกให้เลือก และรับคำสั่งเสียงได้
> ไฟล์โค้ด: `src/coach/` และ `supabase/functions/coach-llm/`

---

## 1. ภาพรวม: NLP 3 ส่วน

```
                 ┌──────────────── Natural Language Generation ────────────────┐
ผล AI ทุกเฟรม ──▶ │ Coach (กฎ + คลังประโยค)  → เลือกว่าจะพูดอะไร เมื่อไหร่        │──▶ Text-to-Speech (th-TH)
                 │ LLM (Claude) → แต่งคำทักทาย / สรุปผล แบบไม่ซ้ำ                │
                 └─────────────────────────────────────────────────────────────┘
ไมโครโฟน ──▶ Speech-to-Text (th-TH) ──▶ Intent detection ──▶ พัก / ต่อ / จบ / ได้กี่ครั้ง
```

| ส่วน | ทำงานที่ไหน | ความเร็ว | ใช้ตอน |
|---|---|---|---|
| NLG แบบกฎ + คลังประโยค | ในเครื่อง | ทันที | ระหว่างฝึก (นับครั้ง, เตือน, ชม) |
| LLM แต่งประโยค | Supabase Edge Function → Claude API | 1–3 วินาที | ก่อนฝึก (ทักทาย) และหลังฝึก (สรุปผล) |
| สั่งงานด้วยเสียง | Web Speech API (Chrome) | ประมาณ 1 วินาที | ตลอดการฝึก (เปิดเองในโปรไฟล์) |

ระหว่างฝึกไม่ใช้ LLM เพราะการเตือนต้องเร็วกว่า 0.3 วินาที

## 2. บุคลิกโค้ช (เลือกได้ในหน้าโปรไฟล์ มีปุ่มลองฟัง)

- **หลานสาวใจดี** – นุ่มนวล ใจเย็น ลงท้าย "ค่ะ" เสียงช้าลงเล็กน้อย
  > "อรุณสวัสดิ์ค่ะ คุณยายสมศรี วันนี้มาฝึกขาให้แข็งแรงกันนะคะ"
- **โค้ชสายเชียร์** – กระตือรือร้น ลงท้าย "ครับ" เสียงเร็วขึ้น
  > "8! เหลือ 2 ครั้งสุดท้าย เต็มที่!"
- **เพื่อนขี้เล่น** – มีมุกเบาๆ ชวนยิ้ม เสียงสูงขึ้น
  > "ท่าสวยจนกล้องอิจฉาค่ะ"

แต่ละบุคลิกมีคลังประโยค 2–3 แบบต่อสถานการณ์ และปรับความเร็ว/ระดับเสียงของ TTS ต่างกัน

## 3. กติกาการพูดระหว่างฝึก (Coach)

**นับครั้ง (ทุกครั้งที่นับได้)**
- ปกติพูดแค่ตัวเลข "1", "2", "3" สั้นและไม่รบกวน
- ครึ่งทาง: "5 ครั้งแล้ว ครึ่งทางแล้วนะคะ"
- 3 ครั้งสุดท้าย: "8 อีก 2 ครั้งสุดท้ายแล้วค่ะ"
- ทำถูกติดกัน 3 ครั้ง → เติมคำชม
- ครั้งก่อนผิด ครั้งนี้ถูก → ชมว่าแก้ท่าได้ ("ดีขึ้นแล้วค่ะ")

**เตือนท่าผิด (เมื่อสถานะเปลี่ยนเป็นเหลือง/แดง)**
- ผิดครั้งแรก → บอกสั้นๆ ว่าผิดอะไร: "ระวังเข่าบิดเข้าในค่ะ"
- ผิดซ้ำ → บอกวิธีแก้: "ลองให้เข่าชี้ไปทางเดียวกับปลายเท้านะคะ"
- ระดับแดง → ขึ้นต้นด้วย "หยุดก่อนค่ะ" และ **ตัดเสียงที่พูดอยู่ทิ้งเพื่อพูดทันที**
- คำเตือนประเภทเดียวกันพูดซ้ำได้หลัง 3.5 วินาที (กันพูดรัว)

**ลำดับความสำคัญของเสียง**
- `high` ตัดคิวพูดทันที: เตือนแดง, เริ่ม, พัก, ครบเซต, สรุปผล
- `normal` ต่อคิว: นับครั้ง, เตือนเหลือง
- `low` ข้ามถ้ากำลังพูดอยู่

**ไม่ซ้ำเดิม:** สุ่มประโยคจากคลัง และจะไม่เลือกประโยคเดียวกับครั้งก่อนในหมวดเดียวกัน

## 4. LLM แต่งประโยค (Claude API)

**ก่อนฝึก (greeting)** – ขอไปพร้อมกับตอนโหลดโมเดลกล้อง พูดเมื่อกล้องพร้อม
ข้อมูลที่ส่ง: ชั่วโมงของวัน, กลุ่มผู้ป่วย, จำนวนรอบวันนี้, ฝึกครั้งล่าสุดกี่วันก่อน, % ท่าถูกครั้งก่อน, คะแนนปวดครั้งก่อน

**หลังฝึก (summary)** – พูดในหน้าสรุปผล และแสดงเป็นข้อความบนจอ
ข้อมูลที่ส่ง: จำนวนครั้ง, % ท่าถูก, ท่าที่ผิดบ่อยที่สุด, เวลาเฉลี่ยต่อครั้ง, คะแนนปวดก่อนฝึก

**ความปลอดภัยและความเป็นส่วนตัว**
- ส่งเฉพาะตัวเลข **ไม่ส่งชื่อ** LLM ใช้ `{name}` แล้วแอปแทนชื่อเองในเครื่อง
- System prompt บังคับ: ไม่เกิน 2 ประโยค, ไม่วินิจฉัยโรค, ไม่แนะนำยา, ปวด ≥ 7 ให้แนะนำพักและปรึกษานักกายภาพ
- ถ้า LLM ไม่ตอบภายใน 4 วินาที หรือยังไม่ได้ตั้งค่า → ใช้ประโยคสำเร็จรูปจากคลังแทนทันที
- API key เก็บเป็น secret ใน Supabase ไม่อยู่ในแอป

**Model:** `claude-haiku-5-5` (เร็วและถูก) เปลี่ยนได้ด้วย secret `COACH_MODEL`

## 5. สั่งงานด้วยเสียง (Speech-to-Text + Intent)

| พูดว่า (ตัวอย่าง) | คำสั่ง | ใช้ได้ตอน |
|---|---|---|
| เริ่ม, ลุย, ไปกัน | start | เตรียมพร้อม (ต้องเห็นทั้งตัว + เลือกคะแนนปวดแล้ว) / พัก |
| พัก, หยุดก่อน, เหนื่อย | pause | กำลังฝึก |
| ต่อ, ทำต่อ, พร้อมแล้ว | resume | พัก |
| จบ, พอแล้ว, ไม่ไหวแล้ว | finish | กำลังฝึก / พัก |
| ได้กี่ครั้งแล้ว, เหลือกี่ครั้ง | count | กำลังฝึก / พัก → โค้ชตอบ "ทำไปแล้ว 6 ครั้ง เหลืออีก 14 ครั้ง" |

- จับคำด้วยกติกา (keyword rules) ตรวจตามลำดับ count → finish → pause → resume → start
- ระหว่างที่แอปกำลังพูด จะไม่รับคำสั่ง (กันไม่ให้ได้ยินเสียงตัวเอง)
- จอแสดง "ได้ยินว่า: …" ให้รู้ว่าระบบฟังถูกไหม
- **ปิดไว้เป็นค่าเริ่มต้น** เพราะ Chrome ส่งเสียงไปแปลงเป็นข้อความที่เซิร์ฟเวอร์ของ Google (ต้องแจ้งผู้ใช้ตาม PDPA)

## 6. การตั้งค่า

```bash
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
supabase functions deploy coach-llm
```

ไม่ตั้งค่าก็ใช้ได้: โค้ชจะใช้คลังประโยคสำเร็จรูปทั้งหมด

**แก้หรือเพิ่มประโยค:** `src/coach/personas.ts` (`PHRASES`, `ISSUE_PHRASES`)
ใช้ slot ได้: `{name}` `{n}` `{left}` `{set}` `{correct}` `{time}` `{p}`

## 7. แผนต่อยอด
- เสียง TTS ภาษาไทยที่เป็นธรรมชาติกว่าเสียงของเบราว์เซอร์ เช่น Google Cloud Text-to-Speech (th-TH) หรือ Botnoi Voice
- สร้างไฟล์เสียงของประโยคที่ใช้บ่อยไว้ล่วงหน้า (cache) ให้เล่นได้ทันทีโดยไม่ต้องรอเน็ต
- ให้ลูกหลานอัดเสียงตัวเองเป็นเสียงเชียร์ ("แม่สู้ๆ")
